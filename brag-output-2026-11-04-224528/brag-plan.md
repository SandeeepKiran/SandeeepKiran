# Brag plan: Sandeep's GitHub profile

## Answers
- **What is it?** Sandeep Kiran's GitHub profile README, themed like a Genshin Impact character screen (Anemo teal, Albedo gold).
- **Who is it for?** Recruiters, hiring managers and devs who land on github.com/SandeeepKiran.
- **What it does for them:** in one scroll they see who he is (QA Manager who tests AI with AI), his skill tree, and five shipped side projects as "Mousy".
- **What sets it apart:** it is not a static page. A GitHub Action redraws the banner, stats and the contribution snake every night, and every heading icon is a hand-picked Genshin talent icon.
- **Most impressive claim:** five public projects, each with a working "Try it live / Download" link.
- **Visual hook:** the real animated banner, "Hi (waving Venti blob), I'm Sandeep Kiran, aka Mousy", flying in over the Anemo starfield.
- **Real UI to show:** banner SVG, heading icons, skill badges (all 51, colours as in README), project table as cards, live stats + snake SVGs, HoYoWiki cursor from the site.
- **Tone:** `polished` with game-UI flavour: a character-select screen for a person.
- **Share caption:** see share-copy.txt.

## Privacy
No email, phone, city or employer name on screen. The typing-line SVG (it has the employer and email) is not used. The "Internal QA Tool" row is left out.
